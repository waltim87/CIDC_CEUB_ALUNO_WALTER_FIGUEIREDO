CIDC · Arquitetura e operação · 14

Este é o valor de juntar as áreas num sistema só. O alerta aprovado aciona o plano de contingência; as tarefas vão sozinhas para o titular de cada área; a ocorrência recebe equipe e barco; e, quando é resolvida, o barco volta a ficar disponível. Tudo isso foi testado no banco com as contas de teste.
