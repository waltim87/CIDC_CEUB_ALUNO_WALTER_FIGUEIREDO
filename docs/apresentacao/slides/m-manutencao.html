CIDC · Arquitetura e operação · 23

A manutenção cabe numa tabela. As duas tarefas mais comuns: reiniciar o app depois de uma atualização e aplicar mudanças no banco pelo SQL Editor, sempre revisando o SQL antes. Para conferir que nenhuma permissão quebrou, há o script de teste integrado.
