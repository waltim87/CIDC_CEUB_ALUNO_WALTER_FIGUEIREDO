Lição para o framework

Quase todas nasceram de regras reescritas à mão em cada área. Escrita uma vez e testada, a regra vale para todas.

Mostrar isso é sinal de maturidade: o teste existe para encontrar problemas. As cinco brechas foram corrigidas e testadas de novo. A principal lição: quando cada área reescreve a própria regra de acesso, os erros se repetem. Por isso o próximo passo é transformar essas regras num framework único.
