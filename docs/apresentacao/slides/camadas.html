CIDC · Arquitetura e operação · 5

Cada camada tem uma tarefa só. A coleta e os robôs rodam no GitHub Actions, sem servidor ligado o tempo todo. O banco Supabase guarda os dados e, principalmente, as regras de acesso. O painel em Streamlit mostra a cada pessoa só o que o perfil dela permite.
