O caminho do dado: as fontes oficiais são lidas pelos coletores no GitHub Actions a cada 3 horas, gravadas no banco Supabase, analisadas pelo robô, e mostradas no painel Streamlit conforme o perfil de quem entra. O alerta aprovado sai pelo Telegram, só para quem se inscreveu. O banco é o centro: é lá que ficam as regras de quem pode ver e fazer o quê.
